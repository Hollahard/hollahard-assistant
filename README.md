# HollaHard Assistant

Private assistant for connecting ChatGPT to an authorized Discord bot.

The project focuses on bounded Discord reads, message summaries, and reviewed server-management changes. Links and code from Discord messages are treated as text only and must never be opened, executed, or saved for later execution.

## Repository status

This repository is being prepared as the GitHub home for the project source. The initial PR adds safe documentation, testing notes, and repo hygiene files. The hosted app source should be exported and added in a follow-up PR without committing secrets or private connection data.

## Docs

- `docs/architecture.md` explains the generic app flow and safety model.
- `docs/testing.md` gives a manual regression checklist.
- `docs/source-export.md` tracks the source export handoff.
